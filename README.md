<h1>Calculadora Simples</h1>

<h5>Um programa em Python que executa operações matemáticas básicas pelo terminal.</h5>

<h2>Funcionalidades </h2>
<p> Soma </p>
<p> Subtração </p>
<p> Multiplicação </p>
<p> Divisão (com tratamento de erro para divisão por zero) </p>

<h2> Requisitos </h2>
<p> Python 3.6 ou superior instalado </p>
<p> Nenhuma biblioteca externa é necessária</p>


<h2>Como executar </h2>
<p>Abra a pasta do projeto no VS Code.
Abra o terminal integrado (Ctrl + ' ou menu Terminal > Novo Terminal).
Execute o comando:
bash
   python calculadora.py </p>


<h2> Como Usar   </h2>
<p> Ao rodar o programa, um menu será exibido com as opções:</p>
  <p> 1 - Soma (+)</p>
  <p> 2 - Subtração (-)</p>
  <p> 3 - Multiplicação (*)</p>
  <p> 4 - Divisão (/)</p>
  <p> 5 - Sair</p>
  
<p>Digite o número da operação desejada e pressione Enter.
Informe o primeiro e o segundo número quando solicitado.
O resultado será exibido na tela.
O menu volta a aparecer para uma nova operação, até que você escolha a opção 5 para sair.</p>


<h2>Estrutura do código </h2>

<h5>Função	Descrição</h5>
<p>somar()	Retorna a soma de dois números</p>
<p>subtrair()	Retorna a subtração de dois números </p>
<p>multiplicar()	Retorna a multiplicação de dois números </p>
<p>dividir()	Retorna a divisão, com verificação de divisão por zero </p>
<p>obter_numero()	Valida a entrada do usuário, garantindo um número </p>
<p>exibir_menu()	Mostra o menu de opções no terminal </p>
<p>main()	Controla o fluxo principal do programa </p>
